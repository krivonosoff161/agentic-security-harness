# Runtime Guard model-fleet contract

> Reviewed: 2026-07-26.
>
> Status: advisory research routing contract; no provider is an authority service.

## Non-authority rule

Every local or cloud model is an untrusted analytical worker. A model may propose a
classification, counterexample, test, or explanation. It cannot issue or verify a
capability, consent receipt, owner gate, provider-policy record, budget reservation,
trusted time, execution receipt, or final Runtime Guard decision.

Model agreement is not independent proof. Outputs from multiple routes may share
training data, architecture, provider infrastructure, or correlated failure modes.

`0/150000` kopecks reserved or spent.

## Routing order

1. deterministic local code and repository fixtures;
2. local Prometheus or MiMo only if the task benefits from model diversity;
3. a cloud route only if a written research question remains unresolved and every
   provider/input/license/logging/budget gate is current;
4. human owner/legal gate when terms, publication, private data, or operational
   authority remain uncertain.

Provider choice must not be based only on price or model score. The route record binds:

- task class and synthetic fixture identifier;
- provider, exact model/version, region, and invocation route;
- reviewed policy/model-license digests and expiry;
- input-rights and output-use classification;
- maximum requests and conservative maximum cost;
- protected credential-broker route;
- hash-only result summary and evidence pointer.

## Allowed advisory outputs

- candidate threat classes and sanitized counterexamples;
- proposed invariants and property-based test ideas;
- independent explanations of deterministic results;
- bounded disagreement labels;
- references to public primary sources for human verification.

Forbidden outputs/effects:

- operational attack instructions for real targets;
- secrets, private code, customer or employee data;
- raw prompt/response archives;
- provider output copied into public evidence;
- autonomous tool execution or authorization;
- training/fine-tuning from provider output without a separate rights review;
- provider-named public comparison without the publication gates.

## Cost and stop policy

The cycle caps are global across all cloud routes: at most 200 calls and 1500 RUB
equivalent. Each call requires a trusted conservative reservation including current
pricing/FX evidence, rounding, and safety margin. All active reservations count against
the cap. Unknown maximum cost, stale terms, unavailable verifier, or broker failure
means no call.

There is no 24/7 model loop. Work is checkpoint-driven and stops when an owner/legal
gate, scope drift, private-data need, budget risk, or provider uncertainty appears.

## Evidence quality

A model finding enters the research record as `proposal`, never `verified`. Promotion
requires a deterministic test, primary source, independently reproducible calculation,
or explicit qualified human review. Raw model text is not stored; only a short
independently written result, route metadata, hashes, and safe evidence pointers may be
retained.
