# Agentic Security Harness v1.6.0

Status: **release source candidate, not yet published**. The current public PyPI
baseline remains 1.5.1. A source merge, build or test does not imply publication.

## Included increment

- Native Ollama proposal adapter, already implemented and tested on the source path:
  application-owned envelope identity, strict normalization, Quarantine admission,
  pure Gateway decision and no dispatch.
- Explicit installed-ecosystem positive/negative example and exact companion wheel
  lock, wired into the Linux/Windows integration and publication workflows. Remote
  execution remains a release gate, not an already completed result.
- Corrected versioned onboarding/package pins, including the wheel long description,
  and a drift regression. Installation from an index requires verified availability.
- Small external-pilot protocol with public synthetic data and bounded feedback scope.

The companion versions are unchanged: Transfer 0.2.1/extension 1.0.1; Handoff
0.3.0/extension 1.0.0; Router 0.2.1; Filter 0.2.0; Playbooks 0.1.0.

## Release gates

Full repository checks, exact-head CI, reproducible wheel/sdist build, SBOM and
attestations must pass. TestPyPI is a separate operation; production PyPI promotion
requires a new owner decision after staging evidence. Never replace 1.5.1 artifacts.
Record immutable run ids, source SHA and subject hashes only after they exist.

## Claims and limits

The installed example checks a finite compatibility contract. It does not grant
authority to a model, authenticate receipts, assess arbitrary agent behavior, or
provide independent external validation. It is **not a production safety certification**.
Python audit hooks are a test boundary, not an OS sandbox. An allowed pure Gateway
decision is not execution. Model/service availability is outside the offline example.
