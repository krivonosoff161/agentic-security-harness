# Agentic Security Harness v1.3.0

This document describes the source-only release candidate for Agentic Security Harness
v1.3.0. The candidate is not itself a tag, GitHub Release, TestPyPI/PyPI publication,
deployment, or production-enforcement claim.

## Highlights

- A closed Extension SDK V1 for canonical observations, advisory findings, results, and
  receipts, with deterministic in-process conformance checks and no automatic discovery.
- Explicit installed-distribution inspection that validates canonical metadata, closed
  entry points, `RECORD`, implementation/configuration digests, and exact reinspection
  before issuing an authority-free approval receipt.
- Metadata-only operator lifecycle commands for inspection, approval, disable receipts,
  rollback plans, and explicit receipt projections. Harness never imports, downloads,
  starts, stops, disables, or rolls back extension code automatically.
- Exact-source Transfer and Handoff extension compatibility, a data-only Playbooks Policy
  Pack adapter, and byte-only Router and Cheap Filter receipt auditors.
- A deterministic Corpus Pack SDK that preserves the frozen 24-pattern corpus 1.0.0,
  rejects replay/collisions/core overrides/unsafe paths, and executes no pack code.
- Provider-neutral offline Security Intelligence contracts with digest-only evidence,
  explicit gaps, advisory outcomes, and no fetching or model call.
- A controlled local-response adapter restricted to an operator-started literal-loopback
  `/v1/responses` endpoint and the Runtime Gateway's two deterministic synthetic tools.
- Canonical ecosystem component manifests, roadmap, compatibility matrix, document
  registry, exact-source lock, and Linux/Windows integration gate.

## Evidence and limitations

The release gate reruns the complete test, Ruff, mypy, Bandit, artifact-validation,
generator, reproducible wheel/sdist, and installed-package smoke contours. A later
tag-authorized workflow must independently bind the exact candidate commit to checksums,
a CycloneDX SBOM, and GitHub/Sigstore attestations before any publication decision.

No surface in this release automatically trusts arbitrary third-party code, verifies a
package signer or operator identity, provides a sandbox, calls a live provider, accepts
credentials, reaches a non-loopback target, executes arbitrary tools or upstream MCP,
grants allow/enforcement authority, or proves production effectiveness. Companion
extensions remain separately packaged source candidates unless their own release gates
say otherwise. The controlled local endpoint is unauthenticated and suitable only for
the bounded operator-controlled local contour described in its contract.

The deterministic and synthetic results are reproducibility evidence, not a production
safety certification. Independent standards validation and independent maintainer review
remain unclaimed.
