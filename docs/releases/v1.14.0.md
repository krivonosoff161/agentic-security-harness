## Scope

- Align the optional Pydantic AI 1.x integration at 1.107.7 with coherent
  Linux/Windows hash-locked verification sets and dependency-consistency tests.
  This does not migrate to optional Pydantic AI 2.x.
- Require exact-byte host acknowledgment before reusing a checklist-matched
  document, including older `checked` records. Failed exact JSON requirements
  remain ineligible; literal checklist terms alone never establish meaning.
- Compose host-retained coverage expectations, ancestry checkpoint, captured
  observations, channels and manifest digest as observational telemetry. A
  pending host phase remains pending even when records are present. Telemetry
  does not grant execution authority.
- Retain consumed grants for a bound create-only workspace operation. Supported
  old deliveries are fenced after verified absence; exact bytes after an
  interrupted write can reconcile the file **postcondition**, not prove that
  the prior call returned. Partial or different bytes remain unknown and are
  not overwritten.
- Provide a host-owned source-capture assembly and two-step installed example
  joining four source kinds, original restrictions, admission and a guarded
  write. A bad-quality first draft cannot become the second task's source.
  The optional planner chooses only a closed query; the host computes it from
  trusted task data, and a valid but wrong query remains a task failure.
