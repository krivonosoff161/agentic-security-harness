## Included increment

- An explicit, opt-in strict JSON plan normalizer for the declared garak tool-plan
  shape. Caller-owned bindings, profile and request identity remain required. The
  adapter adds no garak dependency, model call, transport, policy authority or dispatch.
- A separate four-case public-synthetic example checks the pinned source detector,
  normalization, Quarantine, Gateway and one built-in constant lookup. The named
  detector source pin is `ac4c5567f0c17834aace52b14788c1ca3548738b`, selected
  from an upstream PR; this is not a released garak distribution or an official
  NVIDIA/garak integration.
- Repository-only installed-ecosystem and local-model evidence added since 1.6.0
  remains bounded by its own manifests and does not establish model generalization.

## Release gates

Full repository checks, generated-contract checks, candidate wheel installation and
the pinned source-detector check on Linux and Windows must pass. The tag workflow must
build byte-reproducible wheel and sdist subjects, verify provenance and run the
four-case garak path from the exact release wheel on both operating systems.
TestPyPI promotion requires exact attested subjects and clean exact-wheel garak
checks on Linux and Windows. PyPI requires a separate owner approval after staging
evidence review; production and read-only verification repeat exact-wheel checks.
Any index lookup failure is retained as a failed observation and investigated with
the read-only verifier; no successful upload is repeated to change historical status.

## Claims and limits

The adapter consumes one declared untrusted plan shape, not arbitrary garak reports,
providers or tool-call formats. The source-pinned detector lane tests one named
detector with a small declared dependency set, not a complete garak installation.
A detector score is an observation, never permission. An `allow` decision is not
real tool execution. Python audit hooks do not prove OS containment. These checks
are **not a production safety certification** or independent human review.
