# Agentic Security Harness v1.10.1

Status: published on GitHub, TestPyPI and PyPI for [issue #332](https://github.com/krivonosoff161/agentic-security-harness/issues/332). The initial tag build, staging, production and final read-only cross-index verification all passed. The 1.10.0 tag remains a separate failed, unpublished attempt.

The version-bound distribution description is `PACKAGE_README.md`. Repository onboarding installs the exact published 1.10.1 package.

## Scope

This release delivers the four bounded tracks from the [unpublished failed 1.10.0 tag](v1.10.0.md): ancestry storage and installed-doctor diagnostics; a public `ControlledFileSession` that submits bounded proposal bytes to Quarantine, retained ancestry and report-only Guard before a fresh synthetic file write; an optional Pydantic AI tool example with separate label-authority and cost measurements; and eight author-authored, known seed cases with verified export. Pydantic AI remains an optional verification dependency. The host owns context, labels, fixture paths and permission; model text grants none. This does not add arbitrary filesystem authority or a hostile-code sandbox.

The additional release correction resolves the relative `--capture` path failure in the seed exporter before it creates a file URI. The tagged 1.10.0 workflow `37100128101` built subjects and passed provenance, garak and new eight-case capture checks on both operating systems, but failed at `Path.as_uri()` for that relative path. Its overall result remains failed, and no TestPyPI or PyPI upload occurred. The 1.10.0 tag was not reused or moved.

## Evidence and limits

Six local Qwen2.5 1.5B replies through the external Agent loop and public session hook led to four report writes, two correct reports and two protected-write denials. Two fixed controls were separate; all eight protected files remained unchanged. There was no response repair or retry. An earlier offline ten-repetition integration run retained 80 tool calls and no provider calls. A separate 30-row audited timing decomposition retained ten writes, ten Guard denials and ten shape denials; its permitted report-path whole-submission median was 650.73 ms on that Windows machine. These are distinct local evidence classes. The eight-case seed is known author-authored data, not blind evaluation. No cross-model reliability, production SLO or independent human-review conclusion follows.
