# Agentic Security Harness v1.5.1

This document describes the v1.5.1 release source. Source metadata is not proof of
publication: exact tag-bound builds, staging, owner-approved production promotion,
index hashes and installed-package checks are separate gates.

## Scope

- The passive `router` and `all` extras now select `agentic-llm-router==0.2.1`,
  including the reviewed lazy HTTP-client import repair from Router PR #12.
- Ecosystem CI and the reviewed Router receipt producer are rebound to that release
  source. Receipt schema and accounting implementation are unchanged; the new source
  pin intentionally rejects old or mismatched producer identities.
- Scoped dependency updates cover Ruff 0.16.8, build 1.6.1, Pydantic 2.13.5 and
  pydantic-core 2.46.5, plus exact CodeQL v4.38.0 action commits. Windows colorama
  remains present in the hash-locked environment.
- All other companion versions and existing opt-in Connector/Gateway APIs are unchanged.
  Installing a companion still does not discover, bind, activate or execute it.

## Verification and limits

Required gates are the complete synthetic test suite, Ruff, mypy, generated contracts,
artifact validation, reproducible wheel/sdist builds, exact ecosystem integration,
Linux/Windows installed-package quickstarts and public-index hash verification.
The Router import regression additionally forbids process/network creation before effect.

These are bounded installation and contract checks, not a production safety certification,
model-quality assessment, authenticated custody proof or authority to dispatch real actions.
Fresh real-model no-op evidence belongs to the separate private Lab campaign, not this
release source. Independent human standards review remains a separate open item.

Historical [v1.5.0 publication evidence](v1.5.0.md#publication-evidence) remains intact;
no old release artifact or result is replaced.
