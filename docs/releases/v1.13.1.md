# Agentic Security Harness v1.13.1

Status: **candidate preparation**, 2026-10-09. The current published release
remains [v1.13.0](v1.13.0.md). This record does not claim that a v1.13.1 tag,
GitHub release, TestPyPI or PyPI artifact exists.

## Patch scope

This release candidate stabilizes the routes already shipped in v1.13.0. It
adds no connector, model transport, permission, arbitrary executor, or new
research claim.

- The installed-package first run now validates its generated bundle without
  checkout assets or a blocking service. The checkout-only fake server and
  synthetic Gateway are clearly optional. The custom-adapter example now
  emits nonempty synthetic findings, scorecard, manifest-bound evidence and
  HTML rendered from a validated bundle. The HTML itself is not manifest-hashed.
- The document guide leads with a first job and requires deliberate inspection
  of exact prior bytes before a review-required handoff. A matching digest is
  not proof of human review, factual accuracy or permission to act. The
  same-ID concurrency paths return a no-effect existing-job refusal rather
  than leaking a preview or reservation exception. The create-only Guard and
  one-model-call limit remain unchanged.
- Version-bound writer, document and replay instructions use the same 1.13.1
  distribution; following their installation steps does not downgrade it.
- Offline model configuration no longer reads as an availability check.
  Invalid Gateway configuration has a fixed, path-free next step. A repeated
  workspace output has a specific, content-free no-effect refusal before any
  new model call. Other configuration and storage failures keep their prior
  generic diagnostics. Published synthetic and future capabilities remain
  separately labeled in the operator guides.
